## Overview

This repository contains the backend services for LabGo, a laboratory inventory management system developed to manage laboratory instruments, issue-return records, and inventory tracking.

The backend handles:
- Instrument management
- Issue & return operations
- Inventory quantity updates
- Authentication
- Database communication

---

## Features

- REST API implementation
- Instrument CRUD operations
- Issue & return management
- Inventory tracking
- Authentication support
- Database integration

---
